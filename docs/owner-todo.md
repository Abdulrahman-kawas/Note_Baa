# ما عليك أنت: قائمة المهام

هذا الملف يجمع كل ما لا أستطيع إنجازه من بيئتي (لا Mac، ولا حساباتك، ولا جهاز الآيباد). مأخوذ من `docs/agents/judge-verdict.md` (القسم 4 والقسم 12)، مع ما أُنجز في الكود.

الرموز: ⬜ عليك، 🔁 تحتاج تجربة على الجهاز، ✅ منجز في الكود.

## 1. Mac وXcode (أولاً، قبل أي شيء آخر)

- ⬜ **تأكد من إصدار iPadOS على الآيباد.** إن كان 27 فاحتجت Xcode 27. وإن كان 26.x فيكفي Xcode 26.4 أو أحدث. هدف النشر يبقى `26.0`.
- ⬜ **اختر Team في Xcode:** الهدف Dawwen ← Signing & Capabilities. غيّر `com.abdulrahmankawas.dawwen` إن ظهر تعارض.
- ⬜ **أضف هدف الاختبارات `DawwenTests`:** File ← New ← Target ← Unit Testing Bundle، واجعل مجلده `DawwenTests/`. الملفات موجودة (`GapMathTests.swift`، و`AudioPartFileTests.swift`)، فقط أضف الهدف.
- ⬜ **أضف هدف الـ Widget للنشاط المباشر (Live Activity):**
  1. File ← New ← Target ← Widget Extension. فعّل **Include Live Activity**، واسمه `DawwenWidget`.
  2. احذف الملفات النموذجية التي ينشئها Xcode.
  3. ✅ الملفات موجودة في مجلد `DawwenWidget/`. أضفها لهدف الـ Widget (File Inspector ← Target Membership).
  4. ⬜ أضف `Dawwen/Recording/LectureActivityAttributes.swift` لهدف الـ Widget أيضاً. الملف مشترك بين الهدفين.
- ⬜ **أول بناء:** ⌘B. توقع جولة تصليح لأخطاء المترجم، لأن كود Swift لم يُترجم بعد. CI أيضاً سيبني التطبيق على macOS، وسيُظهر الأخطاء.
- ⬜ **Developer Mode على الآيباد:** الإعدادات ← الخصوصية والأمان ← Developer Mode.
- ⬜ **عضوية Apple Developer Program (99 $ سنوياً).** التوقيع المجاني ينتهي كل 7 أيام. وهي شرط لـ TestFlight ولاستحقاق PCC.
- ⬜ **TestFlight (اختياري):** أنشئ سجل التطبيق في App Store Connect، ثم Product ← Archive ← Distribute ← TestFlight Internal.

## 2. أول تشغيل على الآيباد

- ⬜ امنح الأذونات: المايكروفون، والتعرف على الكلام، والإشعارات، والكاميرا (عند أول التقاط شريحة).
- ⬜ **قبل أول محاضرة، من الإعدادات داخل التطبيق، وعلى Wi-Fi:** «نزّل نموذج التفريغ»، و«نزّل لغتي الترجمة» (الإنجليزية ← العربية). يجب أن تظهر «جاهزة دون إنترنت».
- ⬜ **Apple Intelligence** مفعّل للملخص المجاني على الجهاز: iPad بشريحة M1 أو أحدث، أو A17 Pro.
- ⬜ **مايكروفون لاسلكي على المحاضر** بمستقبل USB-C (موصى به بشدة، لأنه يحسن التفريغ أكثر من أي تغيير برمجي).
- ⬜ **اختبار الاختصار الصوتي:** افتح تطبيق الاختصارات، وابحث عن «محاضرة جديدة» تحت دوّن. أو قل «ابدأ محاضرة في دوّن».

## 3. اختبارات القبول على الجهاز (🔁)

هذه الاختبارات لا أستطيع تنفيذها. التفاصيل في القسم 10 من الحكم:

- 🔁 **تسجيل 4 ساعات** بالإنجليزية مع ترجمة عربية. يُسجَّل الاستهلاك والحرارة.
- 🔁 **قتل التطبيق أثناء التسجيل:** يجب ألا يضيع أكثر من ثانية من الصوت، وأن يُصلَح الجزء المفتوح عند الفتح التالي.
- 🔁 **مقاطعات:** مكالمة، Siri، إخراج السماعة. يجب أن يستأنف التسجيل تلقائياً أو يُنبَّه المستخدم.
- 🔁 **قفل الشاشة:** الترجمة تكمل، والنشاط المباشر يظهر على شاشة القفل.
- 🔁 **اختبار WER للتفريغ الإنجليزي:** `server/tools/wer_eval.py` على 3 محاضرات حقيقية، مع تصحيح 10 دقائق يدوياً من كل واحدة. يقارن Apple وSoniox وWhisper.
- 🔁 **اختبار الترجمة الأعمى:** `server/tools/translation_blind_test.py`، على 200 جملة. يقرر إن كان التحسين بـ Haiku يستحق التكلفة.
- 🔁 **الترقية من 0.1:** إذا كان لديك بيانات من النسخة الأولى، تأكد أنها تفتح بعد الترقية (شاشة الاسترداد إن فشلت).

## 4. المفاتيح والحسابات

- ⬜ **Anthropic:** console.anthropic.com ← Workspace باسم `dawwen` بحد إنفاق شهري (مثلاً 10 $) ← API key. ضعه في التطبيق من الإعدادات، أو في SSM إن استخدمت البوابة.
- ⬜ **Soniox:** لا تشترِه قبل نتيجة اختبار WER. **لا رصيد مجاني** للحسابات الجديدة.

## 5. AWS (اختياري، لكن مطلوب إن أردت النسخ الاحتياطي خارج الآيباد)

1. ⬜ أنشئ الحساب. فعّل MFA على root، وأنشئ مستخدم IAM Identity Center للاستخدام اليومي.
2. ⬜ **اختر المنطقة:** القالب يفترض `eu-central-1`. وإن أردت الخليج فاختر `me-central-1`، وغيّرها في `server/samconfig.toml`.
3. ⬜ **ثبّت الأدوات على الـ Mac:** AWS CLI v2، وSAM CLI، وDocker Desktop (أو OrbStack). ثم `aws configure sso`.
4. ⬜ **الأسرار في SSM** (SecureString، بدون تكلفة):
   ```bash
   aws ssm put-parameter --name /dawwen/anthropic_api_key --type SecureString --value 'sk-ant-...'
   python server/tools/issue_device_token.py --name ipad --apply    # يطبع رمز الآيباد مرة واحدة فقط
   python server/tools/issue_device_token.py --worker --apply       # فقط إن شغّلت العامل المنزلي
   ```
5. ⬜ **النشر:** `cd server && sam build && sam deploy --guided`. أدخل `AlertEmail`. المخرج `GatewayUrl` يُلصق في التطبيق ← الإعدادات ← الخادم، مع رمز الجهاز.
6. ⬜ **أكّد اشتراك التنبيهات** من بريدك. القالب ينشئ Budget بـ 5 $.
7. ⬜ **فعّل Cost Anomaly Detection** (مجاني).
8. ⬜ **حصة GPU: لا تطلبها الآن.** تُطلب فقط إن فشل Apple وSoniox في اختبار WER، ولم يتوفر عتاد منزلي.
9. ⬜ **النسخة المنزلية الثالثة (اختياري):** مستخدم IAM `dawwen-home-backup` بقراءة فقط على `devices/*`. السياسة في القسم 4.3 من الحكم.

## 6. الخادم المنزلي (اختياري)

- ⬜ **للنسخ الاحتياطي فقط:** أي جهاز Linux أو NAS عليه Docker، ثم `docker compose -f server/docker-compose.home.yml --profile backup up -d`.
- ⬜ **لتحسين الترجمة بنموذج محلي** (فقط إن فاز في الاختبار الأعمى): Linux مع NVIDIA بذاكرة 16 GB أو أكثر. على Mac: شغّل `ollama` و`worker.py` أصلياً، لأن Docker لا يصل للـ GPU هناك.
- ⬜ لا تفتح أي منفذ. كل الاتصالات صادرة عبر HTTPS.
