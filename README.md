# دوّن — Dawwen

تطبيق آيباد يسجّل المحاضرات الطويلة (حتى 4 ساعات)، ويفرّغها نصاً أثناء الكلام، ويترجم كل جملة، ويلخّص المحاضرة بالذكاء الاصطناعي.

## ما يفعله

- **تسجيل آمن للمحاضرات الطويلة:** الصوت يُحفظ على أجزاء مدة كل منها 5 دقائق (AAC أحادي 16 kHz، نحو 15 MB للساعة)، فلا يضيع أكثر من آخر جزء إن انهار التطبيق. يستمر التسجيل عند قفل الشاشة.
- **تفريغ لحظي:** Apple SpeechAnalyzer على الجهاز (مجاني ودون إنترنت)، وSoniox السحابي لأعلى دقة في العربية.
- **ترجمة لحظية:** Apple Translation على الجهاز، دون حد لعدد الترجمات.
- **ملخص للدراسة:** Claude (Opus 5.5 افتراضياً) يقرأ المحاضرة كاملة ويكتب المحاور بطوابعها الزمنية والمصطلحات وأسئلة المراجعة. بديل مجاني على الجهاز عبر Apple Intelligence للغات التي يدعمها.
- **اسأل المحاضرة:** أسئلة حرة تجيب عنها Claude من النص مع الطوابع الزمنية.
- **تشغيل متزامن، علامات، بحث، تصدير** (TXT وMarkdown وSRT وM4A)، واستيراد ملفات صوتية.

## المتطلبات

| | |
| --- | --- |
| الجهاز | iPad بنظام iPadOS 26 أو أحدث (يعمل على iPhone أيضاً) |
| التطوير | Mac مع Xcode 26 ومنصة iOS 26 مثبتة (Xcode ← Settings ← Components) |
| اختياري | مفتاح [Claude API](https://console.anthropic.com) للتلخيص، ومفتاح [Soniox](https://console.soniox.com) لتفريغ العربية سحابياً |

## التشغيل على الآيباد

1. افتح `Dawwen.xcodeproj` في Xcode.
2. اختر الهدف **Dawwen** ← **Signing & Capabilities** ← **Team**: حساب Apple ID الخاص بك. غيّر **Bundle Identifier** إن ظهر تعارض.
3. صِل الآيباد بالكابل، ثم فعّل على الآيباد: الإعدادات ← الخصوصية والأمان ← **Developer Mode**.
4. اختر الآيباد من شريط الأجهزة واضغط **Run** (⌘R).
5. أول مرة: على الآيباد، الإعدادات ← عام ← VPN وإدارة الجهاز ← ثق بشهادة المطوّر.

بحساب Apple ID مجاني ينتهي توقيع التطبيق بعد 7 أيام فتعيد تشغيله من Xcode؛ عضوية Apple Developer Program (99 $ سنوياً) تمدّ التوقيع لسنة وتتيح TestFlight.

## المفاتيح والخصوصية

أدخل المفاتيح من شاشة الإعدادات داخل التطبيق؛ تُحفظ في Keychain الجهاز فقط. الصوت والنص يبقيان على الآيباد، ولا يغادره إلا الصوت عند اختيار Soniox، والنص عند طلب ملخص أو سؤال من Claude.

## بنية الكود

```
Dawwen/
  App/            نقطة الدخول والإعدادات
  Models/         Lecture و TranscriptSegment (SwiftData)
  Audio/          التسجيل على أجزاء، جلسة الصوت، المشغّل
  Transcription/  Apple SpeechAnalyzer، Soniox WebSocket، التفريغ من الملف
  Translation/    طابور Apple Translation
  Summarization/  Claude API (بث SSE + prompt caching)، Apple Foundation Models
  Recording/      منسّق جلسة التسجيل
  Features/       واجهات SwiftUI (المكتبة، التسجيل، التفاصيل، الإعدادات)
  Export/         TXT و Markdown و SRT و M4A
Config/Info.plist وضع الصوت في الخلفية ومشاركة الملفات
```
