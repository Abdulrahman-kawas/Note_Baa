# دوّن — Dawwen

تطبيق آيباد يسجّل المحاضرات الطويلة (حتى 4 ساعات)، ويفرّغها نصاً أثناء الكلام، ويترجم كل جملة إلى العربية، ويلخّص المحاضرة بالذكاء الاصطناعي.

## ما يفعله

- **تسجيل آمن للمحاضرات الطويلة:** الصوت يُحفظ على أجزاء مدة كل منها 5 دقائق، فلا يضيع أكثر من آخر جزء إن انهار التطبيق. يستمر التسجيل عند قفل الشاشة. التسجيل يبدأ قبل محرك التفريغ، فلا تضيع بداية المحاضرة.
- **تفريغ لحظي للإنجليزية:** Apple SpeechTranscriber على الجهاز (مجاني ودون إنترنت). وSoniox السحابي اختياري للمتحدثين بلكنات قوية أو لتعبئة الفجوات.
- **ترجمة لحظية إلى العربية:** Apple Translation على الجهاز، دون حد لعدد الترجمات، وتعمل بعد تنزيل حزمة اللغة مرة واحدة. الترجمة لا تعتمد على شاشة التسجيل، فلا تضيع جمل إذا قفلت الشاشة.
- **تحسين الترجمة (اختياري):** مراجعة بعد المحاضرة بـ Claude Haiku مع المسرد الخاص بكل مادة، بتكلفة تقريبية 0.03 إلى 0.06 $ للمحاضرة.
- **ملخص للدراسة:** ملخص مجاني على الجهاز بالإنجليزية ثم يُترجم إلى العربية. وClaude Sonnet 5.5 للملاحظات المفصّلة عند الطلب.
- **اسأل المحاضرة:** أسئلة حرة تجيب عنها Claude (Haiku 5.5) من النص مع الطوابع الزمنية.
- **تشغيل متزامن، علامات، بحث، تصدير** (TXT وMarkdown وSRT وM4A)، واستيراد ملفات صوتية.
- **نسخ احتياطي خارج الآيباد (اختياري):** عبر بوابة AWS صغيرة إلى S3 مشفّر، انظر `server/`.

## المتطلبات

| | |
| --- | --- |
| الجهاز | iPad بنظام iPadOS 26.4 أو أحدث (يعمل على iPhone أيضاً)، وiPadOS 27 إن توفّر |
| التطوير | Mac مع Xcode 26.4+ (Xcode 27 إن كان الآيباد على iPadOS 27)، ومنصة iOS مثبتة (Xcode ← Settings ← Components) |
| اختياري | مفتاح [Claude API](https://console.anthropic.com) للتلخيص المفصّل والتحسين، ومفتاح [Soniox](https://console.soniox.com) للتفريغ السحابي |

## التشغيل على الآيباد

1. افتح `Dawwen.xcodeproj` في Xcode.
2. اختر الهدف **Dawwen** ← **Signing & Capabilities** ← **Team**: حساب Apple Developer الخاص بك. غيّر **Bundle Identifier** إن ظهر تعارض.
3. صِل الآيباد بالكابل، ثم فعّل على الآيباد: الإعدادات ← الخصوصية والأمان ← **Developer Mode**.
4. اختر الآيباد من شريط الأجهزة واضغط **Run** (⌘R).
5. أول مرة: على الآيباد، الإعدادات ← عام ← VPN وإدارة الجهاز ← ثق بشهادة المطوّر.
6. من الإعدادات داخل التطبيق، نزّل حزمة الترجمة من الإنجليزية إلى العربية قبل المحاضرة.

بحساب Apple ID مجاني ينتهي توقيع التطبيق بعد 7 أيام فتعيد تشغيله من Xcode؛ عضوية Apple Developer Program (99 $ سنوياً) تمدّ التوقيع لسنة وتتيح TestFlight.

## المفاتيح والخصوصية

أدخل المفاتيح من شاشة الإعدادات داخل التطبيق؛ تُحفظ في Keychain الجهاز فقط. الصوت والنص يبقيان على الآيباد، ولا يغادره إلا:
- الصوت عند اختيار Soniox.
- النص عند طلب ملخص مفصّل أو سؤال أو تحسين ترجمة من Claude.

## الخادم (اختياري)

مجلد `server/` يحتوي بوابة AWS (Lambda + S3 + DynamoDB) في Docker، لا تدخل في مسار التسجيل أبداً، وخادماً منزلياً اختيارياً بلا منافذ مفتوحة. التفاصيل والتكلفة في `docs/agents/judge-verdict.md`.

## بنية الكود

```
Dawwen/
  App/            نقطة الدخول والإعدادات
  Models/         نماذج SwiftData بإصدارات (SchemaV1 مجمّد، وSchemaV2)
  Audio/          أجزاء التسجيل (CAF)، جلسة الصوت، الخط الزمني، المشغّل
  Recording/      منسّق التسجيل، وأمان التسجيل، والتفريغ المتزامن
  Transcription/  Apple SpeechTranscriber، Soniox WebSocket، ملء الفجوات
  Translation/    طابور الترجمة، وجلسات Apple Translation، والتحسين
  Summarization/  Claude API (بث SSE وإعادة المحاولة)، Apple Foundation Models
  Storage/        تخزين المحاضرات، والأرشيف، والنسخ الاحتياطي
  Server/         عميل البوابة
  Features/       واجهات SwiftUI (المكتبة، التسجيل، التفاصيل، الإعدادات)
  Export/         TXT و Markdown و SRT و M4A
Config/Info.plist وضع الصوت في الخلفية
Dawwen/Resources/PrivacyInfo.xcprivacy إقرار الخصوصية (مطلوب لـ TestFlight)
server/          بوابة AWS وخادم منزلي وأدوات القياس
docs/agents/     تقريرا الإيجنتين وحكم الخبير
```
